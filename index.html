Core Features

一个工具，覆盖完整调试流程

串口配置、数据观察、批量命令和屏幕下载互相衔接，减少在多个工具之间反复切换。

01

串口收发

HEX/字符实时收发，支持时间戳、超时分组、自动滚屏、日志与多种字符编码。

02

快捷指令

10页共300条指令，可设置备注、延时、HEX模式和循环发送，兼容 SSCOM INI。

03

校验计算

支持 Modbus CRC16、CCITT、CRC32、ADD和XOR，并可精确选择校验范围。

04

T5L在线下载

调试与下载共用串口，支持13/14/22文件、T5L51代码及下载状态恢复。

05

稳定工作流

窗口布局、串口参数、指令、主题与工程路径自动保存，重新打开即可继续工作。

06

原生 Windows

直接调用 Windows 串口 API，发布为单文件 EXE，无需额外安装运行环境。
