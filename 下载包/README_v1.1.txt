串口助手 v1.1 使用说明
=======================

串口助手是一款面向 Windows 的串口调试与 T5L 在线下载一体化工具。
发布版为单文件 EXE，可直接运行，无需安装 Python、pyserial 或其他运行库。

一、快速开始

1. 选择 COM 端口和波特率，其他参数可在“串口设置”中调整。
2. 点击“打开串口”。
3. 在数据发送区输入文本或 HEX 数据。
4. 按需选择 HEX 发送、自动换行、校验算法及校验范围。
5. 点击“发送数据”，发送和接收内容会实时显示在同一个通讯记录区域。

二、串口调试功能

1. 自动扫描 COM 端口并显示驱动名称。
2. 支持同时创建和打开多个串口，每个串口具有独立标签和收发线程。
3. 绿色状态点表示串口已打开，红色表示已关闭，黄色表示被 T5L 下载占用。
4. 点击标签切换当前串口；通讯记录、收发计数和参数均按标签独立保存。
5. 点击标签右侧 × 可关闭并移除当前标签，不影响其他串口。
6. 支持常用波特率、数据位、校验位、停止位和流控制。
7. 串口打开期间仍可修改参数。
8. 支持 HEX/字符收发以及 GBK、UTF-8、ASCII 编码。
9. 支持接收 HEX 显示、自动滚屏、日志保存和收发计数。
10. 接收数据到达后立即显示；时间戳超时用于判断新的数据组。
11. 同一超时数据组被驱动拆成多次读取时，会连续显示在同一行，不产生无时间戳断行。
12. 每次普通发送、定时发送或快捷发送都会写入当前标签的通讯记录。
13. 支持定时发送和自动追加 CRLF。
14. 每个 COM 口独立保存打开/关闭状态，下次启动自动恢复。
15. 每个 COM 口独立保存波特率、数据位、停止位、校验位和流控制。
16. 每个 COM 口独立保存 HEX显示、时间戳、超时、自动滚屏、发送选项、校验范围及发送框内容。
17. 在“串口设置”中切换端口，会立即显示该 COM 口自己的参数。
18. 连续高速收发采用分批界面刷新并限制内存日志数量，长时间运行时保持响应流畅。
19. 切换高流量串口标签时只快速绘制最近1000条记录，并一次性完成滚动，减少切换卡顿。

三、校验功能

支持 Modbus CRC16、CCITT CRC16、CRC32、ADD8、ADD16 和 XOR8。
校验范围可选择第1至第32字节开始，结束位置支持末尾或倒数第1至第32字节。
校验同时作用于普通发送、快捷指令和循环发送。

HEX 示例：5A A5 04 83 00 14 01

HEX 输入可使用空格、逗号、分号、冒号或短横线分隔，每个字节必须为两位十六进制。

四、快捷指令

1. 共10页，每页30条，可保存300条指令。
2. 每条指令可设置 HEX/字符模式、备注、延时和是否参与循环发送。
3. 双击备注按钮可修改指令名称。
4. 支持导入 SSCOM INI 配置。
5. 通过“快捷指令 -> 显示快捷指令”可打开或关闭右侧区域，显示状态自动保存。

五、T5L 在线下载

1. 点击顶部“T5L 下载”在主窗口内切换，无需打开额外窗口。
2. 下载只临时占用当前串口标签，其他已打开串口仍可继续收发。
3. 下载结束后恢复被占用标签原来的串口状态和参数。
4. 自动记忆上次 DWIN_SET 文件夹和下载列表。
5. 支持选择目录、单独选择文件、移出下载列表。
6. 移出列表只取消该文件的下载，不会删除源文件。
7. 快速选择支持13文件、14文件、22文件和 T5L51.bin。
8. 支持 T5L51 8051代码更新。
9. 支持 ICL 下载前停止 DGUS 刷新的防卡死处理。
10. T5L 下载端口保持独立选择，不跟随串口助手标签切换。
11. T5L 与串口助手选择同一 COM 口时，波特率自动双向同步。
12. 点击快捷文件选项时会检查当前目录；缺少对应文件将弹窗提示并自动取消勾选。
13. T5L 下载页独立保存上次选择的串口和波特率，重新启动程序后自动恢复。

下载过程中请保持供电和串口连接稳定。目标屏幕内核必须支持相应的在线更新协议。

六、界面与配置

1. 提供20种界面风格，分为明亮、深色、科技、护眼和经典五类。
2. 自动保存窗口尺寸与位置、串口参数、发送内容、快捷指令、主题和工程路径。
3. 配置保存在程序同目录的 config.json，移动 EXE 时可按需一同复制。
4. “帮助 -> 使用帮助（离线网页）”可打开内置说明。
5. “帮助 -> 作者主页（在线）”可访问 https://cuijia12.github.io/。

七、运行环境及注意事项

1. 本程序仅支持 Windows，串口层直接调用 Windows API。
2. 同一串口不能同时被其他串口软件占用。
3. 若端口列表未更新，请点击“刷新”并检查 USB 串口驱动。

八、Agent API

1. 程序运行后在本机 127.0.0.1:18765 提供 HTTP JSON 接口。
2. 支持查询状态、打开/关闭串口、发送和读取 HEX/字符数据、启动/停止 T5L 下载。
3. 接口与 GUI 共用串口会话，避免同一串口被两个进程重复占用。
4. 接口只监听本机，并使用 config.json 中的 agent_api_token 鉴权。
5. 完整接口、Codex 与 PowerShell 示例见 AGENT_API.md。
6. POST /api/serial/receive 可读取每个 COM 口的最新接收包，清空 Agent 缓存不会影响界面通讯记录。
