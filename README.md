# C402 Studio

这是 C402 Studio 的个人主页，展示串口助手、迪文屏开发和 T5L 在线下载工具。

## 网站地址

https://cuijia12.github.io/

## 串口助手 v1.1

- Windows 原生多路串口收发
- 300 条快捷指令
- 多种 CRC、ADD、XOR 校验
- T5L 在线下载与 T5L51 更新
- 单文件 EXE，无需安装 Python

## 多路串口

- 支持同时创建并打开多个 COM 口，每个串口使用独立句柄和接收线程。
- 顶部标签状态点：绿色表示已打开，红色表示已关闭，黄色表示正被 T5L 下载占用。
- 点击标签切换当前串口，通讯记录、收发计数和参数跟随标签独立切换。
- 点击标签右侧 `×` 可关闭串口并移除标签，不影响其他串口。
- 每个 COM 口独立保存波特率、数据位、停止位、校验位、流控制和打开/关闭状态。
- 每个 COM 口独立保存接收显示、时间戳、发送选项、校验范围和发送框内容。
- 程序重启后自动恢复各串口标签及其上次开关状态。
- T5L 下载只临时占用下载页面实际选择的串口，其他串口继续正常收发。

## T5L 在线下载

T5L 下载模块集成在串口助手主界面中。开始下载时，程序只临时接管下载页面实际选择的串口；下载完成或停止后恢复该标签原来的串口参数与开关状态，其他已打开串口不受影响。

### 文件管理

- 可以选择完整的 `DWIN_SET` 工程目录，也可以单独添加需要下载的文件。
- 自动识别 `.bin`、`.dzk`、`.hzk`、`.icl` 和 `.wae` 文件。
- 普通资源文件名需要以 `0～63` 的文件 ID 开头；`T5L51.bin` 会自动识别为 8051 程序。
- 文件列表显示文件名、文件 ID、大小和实时下载状态。
- “移出列表”只取消本次下载，不删除磁盘上的源文件；支持右键操作。
- 自动记忆上次打开的工程目录、文件筛选状态和串口设置。
- 快速选择支持 `13TouchFile.bin`、`14ShowFile.bin`、`22_Config.bin` 和 `T5L51.bin`；取消勾选会从列表移除，再次勾选可恢复。
- 快捷选择对应文件不存在时会弹窗提示，并自动取消无效勾选。
- T5L 端口保持独立选择；与串口助手选择同一 COM 口时，波特率自动双向同步。

### 下载流程

- 按文件 ID 顺序下载资源文件，并实时显示当前文件、写入状态和百分比进度。
- 数据先写入 T5L RAM 缓存区，再执行 Flash 写入命令；每个写入阶段都会检查屏幕应答。
- 下载失败、串口异常或用户停止时会及时结束任务，并尽力恢复屏幕和串口状态。
- 全部资源写入完成后发送复位命令，并等待检测到屏幕重新上线后才提示完成，避免软件提示与屏幕实际状态不同步。

### T5L51 / 8051 更新

- 支持下载 `T5L51.bin`，文件最大为 `64 KB`。
- 8051 程序从变量存储区 `0x8000` 开始缓存，随后通过 `OS_Update_CMD` 写入内部 Flash。
- 写入完成后显式复位，并确认屏幕重新上线。

### ICL 防卡死处理

- 下载 `.icl` 文件前，通过系统变量接口停止 DGUS 刷新，防止界面同时读取正在更新的资源而出现混合数据或卡死。
- 下载成功后统一复位；如果下载失败，也会尝试发送复位命令恢复屏幕运行。

> 下载前请确认串口连接可靠、供电稳定，文件与屏幕型号匹配。Flash 写入过程中不要断电或拔掉串口。
